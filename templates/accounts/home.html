Security Architecture

Security built into the healthcare workflow.

Different cryptographic mechanisms address different security requirements within MediSecure.

Confidentiality

AES-256-GCM

Sensitive diagnosis information is encrypted before being stored in the database.

Authenticity

Ed25519

Doctor-issued prescriptions are digitally signed so their authenticity can be verified.

Integrity

SHA-3-256

Cryptographic hashes and hash chains help detect unauthorized modifications to medical records.
