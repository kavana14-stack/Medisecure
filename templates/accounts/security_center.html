Protection Overview

MediSecure uses complementary security mechanisms, with each cryptographic control addressing a different security requirement.

Confidentiality AES-256-GCM protects sensitive diagnosis information from unauthorized database access.
Authenticity Ed25519 signatures provide verification of doctor-issued prescriptions.
Integrity SHA-3-256 hashing and chained record references expose unauthorized modifications.
