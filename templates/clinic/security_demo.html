SECURITY DEMONSTRATION

🔐 Cryptography Security Demonstration

Live demonstration of AES-256-GCM, Ed25519 digital signatures, and SHA-3-256 hashing used in MediSecure.

ALGORITHM 1

🔐 AES-256-GCM — Encryption

AES-256-GCM protects confidential medical information by converting readable plaintext into encrypted ciphertext.

ALGORITHM 2

✍️ Ed25519 — Digital Signature

Ed25519 is used to digitally sign prescription information and verify that the prescription has not been changed after signing.

Live demonstration:

First click SCAN & VERIFY without changing the prescription.

The system creates the original Ed25519 digital signature and verifies it.

You should see: ✓ SIGNATURE VALID

Now manually add a full stop . to the prescription.

Do not generate a new signature. Click SCAN & VERIFY again.

The original signature is checked against the modified prescription.

Expected result: ✗ SIGNATURE INVALID
ALGORITHM 3

#️⃣ SHA-3-256 — Data Integrity

SHA-3-256 generates a cryptographic fingerprint of the medical record. Any change in the data produces a different hash.

Live demonstration:

First click GENERATE & VERIFY HASH with the original clinical notes.

The system stores the original SHA-3-256 hash for this demonstration.

Then manually change the clinical notes. For example, add one full stop .

Click GENERATE & VERIFY HASH again.

The new hash will be compared with the original hash.

Expected result: ✗ HASH MISMATCH — DATA HAS BEEN MODIFIED
